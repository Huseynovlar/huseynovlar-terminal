## 2. Exact Backend API Contracts & Defensive Field Alignment (`PROJECT.md` §2–§4)
- **Profile & Preferences**: `GET/PATCH /profile/me` (`{id?, username?, role?, totp_enabled?, display_name, email?, bio, avatar_url, social_links, preferences?}`); `GET/PATCH /profile/preferences` (deep-merge `theme_preset:"tangerine"`, `sidebar_variant:"floating"`, `density:"bloomberg"`, `language`, `timezone:"UTC"`, `sound_enabled`, `ticker_enabled`, `ticker_speed`, `hidden_page_ids`, `sidebar_order`, `custom_hotkeys`).
- **Security (`/dashboard/security`)**: `POST /auth/change-password` (`{current_password, new_password, revoke_other_sessions}`); `POST /auth/2fa/setup` -> `{secret, provisioning_uri, qr_svg}`; `POST /auth/2fa/verify` (`{code}`) -> `{ok, totp_enabled, backup_codes: string[]}`; `POST /auth/2fa/disable` (`{password, code}`); `GET /auth/webauthn/credentials` (`{id, device_name, sign_count, transports?, created_at, last_used_at}`), `POST /auth/webauthn/register/options` -> `prepareCreationOptions` -> `POST /auth/webauthn/register/verify` (`{device_name, credential: serializeCredential(cred)}`), `DELETE /auth/webauthn/credentials/{id}?totp_code=`.
- **Sessions, Login History & Audit**: `GET /auth/sessions`, `GET /auth/sessions/{id}`, `DELETE /auth/sessions/{id}`, `POST /auth/sessions/revoke-others`; `GET /auth/login-history?action=&ip=&limit=`, `GET /auth/login-history/{id}`; `GET /auth/ip-lookup/{ip}` (`{ip, is_private, is_netbird, country, country_code, city, region, isp, lat, lon}`); `GET /audit?action=&resource_type=&user_id=&limit=`, `GET /audit/{id}` (handle `details` / `metadata` JSON object safely).
- **Users RBAC (`/dashboard/users/*`)**: `GET/POST /users`, `GET/PATCH/DELETE /users/{id}` (`{id, username, email?, display_name?, role: "ADMIN"|"OPERATOR"|"VIEWER", is_active, totp_enabled?, last_login_at?, created_at}`; `POST/PATCH` accepts `password`). Guard against self-delete & last-admin demotion/deletion.
- **Containers & Setup (`/dashboard/containers/*`, `/dashboard/setup`)**: `GET/POST /ops/containers` (`POST` sends `{container_name, display_name, host_label}` -> `{id?, name, network_cmd?}`), `GET/PATCH/DELETE /ops/containers/{id_or_name}` (defensively read `c.id || c.name`, `cpu_pct?`, `mem_mb?`, `state`, `status`), `POST /ops/containers/{name}/{start|stop|restart}`, `GET /ops/containers/{name}/logs?tail=200` (`{logs}`), `POST /ops/kill-switch/{account_id_or_login}` (`{confirm_text: "CLOSE ALL"}`); `GET /ops/setup-wizard/{id_or_login}/bridge.set?url_mode=internal|external`, `GET /ops/downloads/ExnessPanelBridge.mq5`, `GET /ops/downloads/ExnessPanelHook.mqh`; `GET /ops/integrations/status`, `POST /ops/alerts/test`, `POST /ops/integrations/gemini-test`.
- **Wiki (`/dashboard/wiki/*`)**: `GET/POST /wiki`, `GET/PATCH/DELETE /wiki/{slug_or_id}` (`{id, slug, title, category, content_md, is_pinned, updated_by?, created_at, updated_at}`).
- **Wave 1 Safe Navigation**: Redirect `/dashboard/infrastructure` -> `/dashboard/containers`, `/dashboard/academy` -> `/dashboard/setup`, `/dashboard/roles` -> `/dashboard/preferences`; delete `-components/*` template bloat in repurposed folders; ensure Group 1–3 sidebar links point to existing working Wave 1 routes (or lightweight aliases) so 0 sidebar links 404 before M5.
